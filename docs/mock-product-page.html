Inter-Agent Communication

Enable seamless coordination between AI agents through a simple, file-based JSON protocol. Perfect for multi-agent workflows, CI/CD integration, and IDE plugins.

  • ✓
    Drop-in Requests
    JSON files in ~/.gemini-repl/queues/input/ are automatically processed
  • ✓
    Structured Responses
    Get responses in ~/.gemini-repl/queues/output/ with full context
  • ✓
    Request Archiving
    Processed requests archived for audit trails and debugging
  • ✓
    Context Passing
    Include file contents, line numbers, and project metadata
